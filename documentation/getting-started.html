Introduction

Getting Started

Set up the project locally using the package scripts supplied with this repository.

Requirements

  • A current Node.js LTS release is recommended.
  • npm is used by the included package scripts.
  • A modern browser for local development.
Project stackReact 19, TanStack Start/Router, Vite, Tailwind CSS 4, Radix UI primitives, ApexCharts, and lucide-react.

Start the project

  1. Extract the purchased package and open its root directory in your editor.
  2. Install project dependencies.
  3. Run the development server and open the local URL Vite displays.
npm install
npm run dev

Build for production

npm run build
npm run preview

The production build is created by the repository's Vite build script. See Installation for deployment basics.

Sample data and persistence

AreaBehavior
AppearanceCustomizer settings persist in browser localStorage; reset restores defaults.
New workspacesEdits, approvals, bookings, assignments, notes, and demo processing generally live in component state and reset when a page is remounted or reloaded.
Separate pagesNew workspaces do not share a backend. A doctor booking does not update the separate Appointments page; bed assignment does not update admissions.
ExportsExports download files through the browser. They do not write to a server or trigger payment/dispatch.

Windows

If PowerShell blocks npm scripts, use npm.cmd and npx.cmd with the same arguments.
