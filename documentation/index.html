Welcome to Edzen

Version 1.0.0

Everything you need to build with Edzen.

Edzen is a premium multipurpose React admin dashboard for SaaS, CRM, eCommerce, analytics, finance, and project operations. This guide covers installation, theming, the page library, and customer customization.
