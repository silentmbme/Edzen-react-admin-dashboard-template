Help

Support

Use this checklist to help support requests receive a clear and efficient response.

Before requesting support

  • Confirm the issue on an unmodified copy when possible.
  • Run the documented install and build commands.
  • Check browser console output and include relevant error details.

What support includes

Template defects

Help identifying reproducible issues in the supplied template.

Setup guidance

Clarification on documented installation and included features.

Usage direction

Guidance for working with existing template patterns.

What support does not include

Custom application development, hosting configuration, third-party service changes, and extensive design customization are normally separate services.

How to report a bug

  1. Write a concise description of what happened and what you expected.
  2. Include the page URL, browser, operating system, and relevant console errors.
  3. Add clear steps that allow the issue to be reproduced.
  4. Include screenshots or a short recording when useful.

Documentation maintenance

npm run docs:build
npm run docs:check

Edit edzen-documentation/pages.json, edzen-documentation/release.json, and edzen-documentation/template.html for guide changes. Both documentation folders are regenerated together. The generator reads routes, navigation, and package.json to keep inventory and dependency references aligned. CHANGELOG.md is regenerated from the same change entries.

Before upgrading

Back up customized files, compare source changes, inspect dependency changes, and verify your backend integrations and data migration requirements. Review the version 1.0.0 changelog and upgrade notes before updating.
